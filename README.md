Este projeto foi desenvolvido com o objetivo de demonstrar a criação e o consumo de serviços web utilizando o framework Laravel. A solução abrange tanto a integração com um serviço externo quanto o desenvolvimento de uma API RESTful completa e estruturada para o gerenciamento de produtos.

Na primeira etapa da aplicação, realizou-se o consumo de uma API externa pública por meio da biblioteca HTTP nativa do Laravel. Para isso, foi criado o controller ExternalApiController e mapeada uma rota dedicada. Ao receber uma requisição, o controller executa uma chamada HTTP do tipo GET para a API pública JSONPlaceholder, processa os dados retornados em formato JSON e os devolve formatados para o cliente, demonstrando a capacidade de integração do sistema com serviços de terceiros.

Na segunda etapa, foi desenvolvida uma API RESTful interna para o cadastro e manutenção de produtos. O desenvolvimento iniciou-se pela criação do model Product e de sua respectiva migration no banco de dados, definindo os campos de identificação, nome, descrição, preço e timestamps. Para garantir boas práticas de arquitetura e o desacoplamento entre a camada de dados e a resposta enviada ao cliente, utilizou-se um API Resource denominado ProductResource, responsável por padronizar e formatar a estrutura dos dados retornados na API, incluindo a conversão de tipos e a formatação de datas.

As regras de negócio e operações da API foram concentradas no ProductController, cobrindo todo o ciclo CRUD: listagem de todos os registros, criação de novos itens com validação dos dados de entrada, exibição de um registro específico, atualização de dados e remoção. O mapeamento dessas operações foi feito de maneira concisa no arquivo de rotas da API utilizando a funcionalidade de rotas de recurso do framework.

A execução do projeto requer a instalação das dependências do Composer, a configuração do arquivo de ambiente, a geração da chave da aplicação, a execução das migrations para criação das tabelas no banco de dados e a inicialização do servidor de desenvolvimento nativo do Laravel. A validação de todos os endpoints foi realizada utilizando a ferramenta Postman, definindo o cabeçalho HTTP Accept como application/json. Foram testadas com sucesso as requisições GET para consulta e listagem, POST para criação de dados via corpo JSON, PUT para atualização de registros e DELETE para remoção, confirmando o funcionamento correto das rotas, validações e respostas da API.
